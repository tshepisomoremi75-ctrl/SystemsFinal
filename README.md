Smart Campus Resource Booking System

The Smart Campus Resource Booking System is a Python-based application developed using Tkinter and SQLite. The system enables lecturers to view available campus resources, create and manage bookings, and cancel reservations. Administrators can manage resources, while the system maintains booking information across multiple campuses

Features
- User Registration and Login
- Resource Management
- View Resource Availability
- Create Bookings
- View and Cancel Bookings
- Multi-Campus Support
- SQLite Database Integration
- Simple Graphical User Interface (GUI)

- Technologies Used
- Python
- Tkinter
- SQLite3
- Object-Oriented Programming (OOP)

 System Roles
- Lecturer
- Campus Administrator
- System Operator

How to Run
1. Open the project in PyCharm.
2. Install Python 3.x if not already installed.
3. Run `main.py`.
4. Register a lecturer account or log in using existing credentials.
